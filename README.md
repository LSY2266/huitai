# huitai
一个跑在自己电脑 / NAS 上的「AI 生图」小工作台

*本应用完全由AI编写*


为什么做这个/n
1.市面上的生图工具大多把参数藏起来，你只能点「生成」，然后对着一个失败的红字猜哪里不对。而中转站的 API 又普遍有自己的脾气：某个字段不认、尺寸只支持三档、GIF 要少发参数、`size` 里的乘号必须是半角……/n
2.它不做的事：不内置任何中转站地址、不内置任何 API Key、不上传你的图到除你自己填的那个接口以外的任何地方。**所有文件全部本地存储**/n
3.在服务器，NAS上也能用，支持win、docker，飞牛fpk软件包（注意公网暴露风险）/n
